// how it works

云端的 CC，用上你本机的能力

应用在本机起 MCP 服务，通过 SSH 反向端口转发映射到云主机的 127.0.0.1。不用公网 IP、不开防火墙，流量全部走你已有的 SSH 连接。

// quick start

三分钟上手

  1. 添加主机填地址和用户名，密码 / 密钥 / ssh-agent 都支持；也能从 ~/.ssh/config 一键导入（含跳板机）。
  2. 检查环境启动台一键检查云主机有没有 Claude Code、登录了没有、装没装 tmux，缺什么给什么命令。
  3. 开始工作双击主机开终端，或者开一个图形对话。
  4. 接上本机工具（可选）在 MCP 工具箱勾选允许访问的目录，主机上开启转发并一键注册，然后对云端 CC 说「读一下我桌面上的 notes.md」。
